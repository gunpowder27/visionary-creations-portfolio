# Technical case studies

## Agent Lobby

**Problem.** An agent handoff is hard to trust if the next person cannot tell what changed or if the record disappears on reload.

**My focus.** Define the handoff and review flow, then specify what should remain visible after a user revisits the room.

**Evidence.** A bounded staging pilot exercised an agent handoff and checked that its state survived reload. This is evidence for that workflow, not a claim that every provider or unattended workflow works.

**Scope.** Private source; no recruiter account is needed to read this case study. A redacted walkthrough would make the workflow easier to inspect and is not included here yet.

## Lumen Studio

**Problem.** Small creative teams spend time turning raw media into captions, a calendar, and files they can hand off.

**My focus.** Map the input-to-export flow and define what a beta user should be able to finish without help.

**Evidence.** Work to date covers the local workflow and targeted checks. A hosted run using the real caption model, followed by a verified ZIP export, is still outstanding. This is not presented as a launch or as a claim about customer usage.

**Scope.** Private source. A sanitized input and its corresponding export should be the first public demo, once that run can be repeated.
